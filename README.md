# 🛠 DevOps Playbook

> 나만의 DevOps 실전 매뉴얼. 개념 정리 + 템플릿 + 트러블슈팅 모음.

## 구성

| 디렉토리 | 내용 |
|-----------|------|
| `01-docker/` | Docker 개념, Dockerfile 템플릿, Compose 샘플 |
| `02-gitlab-ci/` | GitLab CI/CD 파이프라인 템플릿 |
| `03-terraform/` | IaC 모듈 & 환경별 패턴 |
| `04-kubernetes/` | K8s 매니페스트 & 운영 팁 |
| `05-aws/` | AWS 서비스 정리 |
| `projects/` | 실제 구축한 프로젝트 기록 |

## 사용법

각 디렉토리의 `README.md`에서 개념을 확인하고, `templates/` 또는 `manifests/`에서 바로 복사해서 쓸 수 있는 파일을 가져다 씁니다.

문제가 생기면 `troubleshooting.md`를 먼저 확인!
